One kind, funny fortune for a houseplant, in a single line of at most 120 characters — an entry for the [Fortune in a Pot](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9) bounty on make.fun.

## The fortune

> By Tuesday I'll lean three degrees left, and yes, I'm grading your rotation habits.

The plant speaks for itself, in the first person: one concrete detail (three degrees left) and a judgement at the end (grading your rotation habits).

## How it works

`main.py` writes the fortune to `/output/entry.txt`. Nothing else is needed — no network, no secrets, no dependencies beyond Python 3. The output is deterministic: every run writes the exact same 83 characters.

```
python3 main.py
```
